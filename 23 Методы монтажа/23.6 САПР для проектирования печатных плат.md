# **23.6 CAD для проектирования печатных плат**

[Поскольку на рынке представлено множество программных пакетов для проектирования печатных плат (ПП) и доступны услуги по их производству малыми тиражами по низкой стоимости с возможностью оформления заказов в электронном виде, создание ПП никогда не было таким простым для радиолюбителя. Как и в любом процессе сборки или производства, важно понимать терминологию и технологию, чтобы достичь желаемого результата. Поэтому данный раздел содержит подробное описание всего процесса проектирования печатной платы. — *Ред.*]

Основная цель использования программного обеспечения для проектирования печатных плат (ПП) — получение так называемой графики ПП (макета) — графического оформления, используемого для создания рисунка дорожек, обеспечивающих электрическую связь на плате. Исторически графика ПП создавалась вручную на прозрачной плёнке с помощью чёрной ленты и специальных декалей, после чего фотографически уменьшалась. Однако в настоящее время широко доступны бесплатные и недорогие программы, специально разработанные для процесса проектирования ПП. Эти программы не только позволяют эффективно и точно создавать графику, но и генерируют необходимые вспомогательные файлы для коммерческого производства, обмениваются данными с программами для создания принципиальных схем, формируют спецификации (списки компонентов) и даже включают такие функции, как трёхмерная визуализация готовой платы. Хотя файлы графики можно передавать другим лицам для изготовления ПП, исходные файлы, используемые программой САПР, как правило, могут открываться и редактироваться только теми, кто использует ту же самую программу.

При принятии решения об изготовлении печатной платы необходимо учитывать характер самой схемы (например, для схем высоких частот, низкого шума и больших токов требуется дополнительная осторожность). Также следует принимать во внимание доступное время, затраты, альтернативные варианты, требуемое количество, возможность обмена и тиражирования проекта, а также неэлектрические характеристики, такие как тепловые и механические свойства, и требуемую надёжность.

# 23.6.1 Обзор процесса проектирования печатной платы

Процесс проектирования печатной платы начинается с формирования перечня компонентов схемы, определения соединений между ними, габаритных размеров платы, а также любых других физических, тепловых и электрических ограничений или целевых параметров. Значительная часть информации о соединениях и компонентах отражается в принципиальной схеме, поэтому во многих случаях процесс трассировки ПП начинается с ввода схемы в программу создания схем, которая может быть как интегрирована в САПР для печатных плат, так и использоваться как отдельное приложение. (Ввод схемы не является обязательным для трассировки ПП.) После ввода схемы могут стать доступны и другие возможности, например, моделирование схемы, описанное в предыдущих разделах. Чистая и логично организованная принципиальная схема, которую легко редактировать, — это большое преимущество независимо от методов производства и сборки схемы.

На основе данных из схемы и другой исходной информации формируется контур платы, размещаются монтажные и другие технологические отверстия, располагаются компоненты и прокладывается рисунок проводников. После завершения трассировки во многих случаях можно выполнить проверку правил проектирования (DRC) — аналог «орфографического контроля» для схем. Правила проектирования включают информацию о соединениях компонентов и другие параметры, необходимые для выявления проблем, связанных со связностью цепи и технологичностью изготовления. Этот этап позволяет существенно сэкономить время и средства, выявляя ошибки, которые можно исправить вручную, но в противном случае они нивелируют часть преимуществ применения печатной платы.

Заключительным этапом работы в программе трассировки ПП является формирование набора из примерно десятка различных файлов, необходимых для изготовления печатной платы. Вкратце этот набор включает исходные чертежи рисунка проводников, файлы для формирования контура платы, паяльной маски, маркировки (шелкографии) и отверстий.

После этого пользователь загружает набор файлов в компанию-изготовитель печатных плат. Уже через два-три дня ему будет доставлен конверт с готовыми платами, полностью подготовленными к сборке! В качестве альтернативы пользователь может изготовить плату самостоятельно, используя фотомеханические или иные процессы на основе выходных файлов из программы.

# 23.6.2 Типы программ для проектирования печатных плат

Программное обеспечение для проектирования печатных плат (ПП) различается по набору функций, возможностям и стоимости, но для радиолюбителя наиболее интересные варианты для начального освоения относятся к следующим категориям: (см. **таблицу 23.4**)

- 1) Программы с открытым исходным кодом (Open Source): Программное обеспечение для проектирования ПП, такое как *GNU PCB* (**pcb.geda-project.org**) и *KiCad* (**kicad.org**), бесплатно в использовании и не имеет искусственных ограничений. Поддержка осуществляется через пользовательские форумы. Исходный код доступен для самостоятельной доработки. *gschem* — это сопутствующая программа для создания схем, разработанная в рамках проекта *GNU PCB*.
- 2) Бесплатное с ограничениями на использование/функции (коммерческая версия): По крайней мере одна компания выпускает версию своего ПО для проектирования ПП и схем, доступную бесплатно для некоммерческого применения. Несмотря на ограничения по количеству слоёв (два) и максимальному размеру платы (4 × 3,2 дюйма), *Eagle PCB* пользуется большой популярностью среди радиолюбителей. Файлы можно передавать другим пользователям; экспортированные файлы в общепринятых промышленных форматах можно отправлять практически любому производителю ПП. Пакет *Eagle* также включает программу для создания схем.
- 3) Бесплатное с ограничениями на экспорт (коммерческая версия): Несколько производителей ПП предлагают программное обеспечение для создания схем и ПП с проприетарным форматом вывода, привязанным к их услугам по производству плат. *PCB123* от Sunstone Circuits (**www.sunstone.com**, для *Windows*) — один из таких продуктов. Он включает ПО для создания схем и компоновки с поддержкой до четырёх слоёв и размером платы до 12 × 18 дюймов (двусторонняя). За дополнительную плату (за каждый проект) можно экспортировать файлы в общепринятых промышленных форматах. Создание схем включено в базовую версию. *Express PCB* (**www.expresspcb.com**, для *Windows*) также предоставляет возможности создания схем и трассировки ПП, привязанные к услугам производства плат Express PCB, включая услугу Miniboard фиксированного размера (3,8 × 2,5 дюйма). Пропретарное ПО *PCB Artist* от Advanced Circuit (**www.4pcb.com**, для *Windows*) поддерживает импорт нетлистов.
- 4) Бюджетное коммерческое ПО: Многие компании предлагают программы для проектирования ПП и схем в широком ценовом диапазоне — от 50 до нескольких тысяч долларов. Обычно каждая компания выпускает несколько версий, различающихся ограничениями по размеру платы, размеру/сложности схемы и доступным функциям, таким как автоматическая трассировка. Модуль для создания схем может входить в состав некоторых пакетов или приобретаться отдельно.

Руководства и учебные пособия по ПО для проектирования печатных плат описывают не только базовые принципы работы, но и специальные сочетания клавиш и другие горячие клавиши, которые значительно повышают эффективность таких операций, как трассировка дорожек.

# 23.6.3 Создание схемы

Первый шаг в проектировании печатной платы — создание схемы. Трассировку можно выполнить напрямую по бумажной схеме, но значительно проще, если схема вводится (или «захватывается») в электронном виде. Программы для создания схем формируют два результата — графическое изображение схемы и данные об элементах и электрических связях для последующей разводки печатной платы. Эти два раздельных требования могут делать некоторые операции при вводе схемы более сложными, чем это кажется необходимым на первый взгляд. Однако следует помнить, что пользователь создаёт не только наглядное графическое представление цепи, но и задаёт лежащую в её основе электрическую связность.

Обычно схемы размещаются на (виртуальном) листе, соответствующем стандартным форматам бумаги, например 11 × 17 дюймов. Более сложные схемы могут занимать несколько листов с использованием специальных меток или компонентов для обозначения как визуальной, так и электрической связности. Часто логически связанные элементы объединяют в модуль, который на схеме верхнего уровня можно ссылаться как на «чёрный ящик». Для сложных цепей эти возможности чрезвычайно полезны и определяют разницу между запутанной схемой, которой неудобно пользоваться, и упорядоченной, компактной схемой, эффективно передающей функцию и принцип работы цепи.

# **КОМПОНЕНТЫ**

Компоненты (резисторы, конденсаторы и т. д.) на принципиальной схеме либо выбираются из существующей библиотеки, либо создаются пользователем и сохраняются в пользовательской библиотеке. Также компоненты и/или дополнительные библиотеки можно найти в Интернете, хотя каждая программа использует свой собственный формат.

Каждый компонент включает в себя гораздо больше, чем просто форму и номера выводов. Запись в типичной библиотеке компонентов обычно содержит:

*Графический символ (УГО)* — это графическое изображение, отображаемое на принципиальной схеме. Многие компоненты могут иметь одинаковый символ (например, обозначение операционного усилителя может использоваться для различных типов ОУ).

*Выводы (контакты)* — для каждого вывода или точки электрического подключения модель компонента может указывать номер вывода, метку (например, «VDD»), тип вывода (инвертирующий, неинвертирующий) или функцию вывода (общий).

*Посадочное место (footprint)* — данный компонент может поставляться в различных корпусах (например, DIP или для поверхностного монтажа). Многие компоненты могут иметь одинаковое посадочное место (например, ОУ, компараторы и оптопары могут использовать один и тот же восьмивыводный DIP-корпус). Посадочные места включают электрические контакты (выводы), а также механические крепежные отверстия, размеры контактных площадок и контур компонента.

*Номинал* — многие компоненты, такие как резисторы и конденсаторы, имеют идентичные параметры, за исключением значения номинала. Все резисторы мощностью 1/4 Вт могут быть экземплярами одного и того же компонента, различаясь только номиналом и позиционным обозначением.

*Позиционное обозначение* — уникальная ссылка на компонент, например R1, C7, D3. Присваивается при размещении компонента на схеме (часто автоматически и в порядке возрастания).

*Данные о поставщике* — номер детали, поставщик, стоимость и т. д. Эти данные предназначены для формирования спецификации (BOM).

Компоненты обычно размещают на принципиальной схеме, открывая библиотеку и выполняя поиск нужного компонента. Новичку может показаться соблазнительным выбрать компонент, который выглядит «более-менее подходящим», столкнувшись с длинным списком в некоторых библиотеках. Однако даже на этом раннем этапе часто необходимо учитывать физическую реализацию на печатной плате. Например, как «Резистор аксиальный 1/8 Вт», так и «Резистор вертикальный 1 Вт» дадут на схеме одинаковый аккуратно нарисованный символ, но на следующем этапе трассировки печатной платы на основе данных компонента посадочные места будут кардинально различаться.

Добавление новых компонентов в библиотеку в процессе создания принципиальной схемы — явление вполне обычное. Поскольку многие компоненты тесно связаны с уже существующими приборами, процесс обычно состоит в выборе существующего графического обозначения, редактировании его формы и/или параметров компонента, создании новой метки и привязке детали к уже имеющемуся посадочному месту. Примером может служить добавление конкретного типа операционного усилителя. Обычно это требуется сделать один раз, поскольку символы можно сохранить в личной библиотеке (и передать другим). Как правило, проще модифицировать деталь, близкую к требуемой, чем «собирать» новую с нуля.

Символы компонентов, как правило, можно поворачивать и отражать зеркально при размещении экземпляра компонента на принципиальной схеме. Позиционные обозначения (R1, T34 и т. д.) могут задаваться и изменяться пользователем, хотя обозначения по умолчанию обычно присваиваются автоматически в порядке возрастания.

### **СОЕДИНЕНИЯ**

Программа для создания принципиальных схем обычно предусматривает режим построения электрических соединений, называемый «сетями» (nets). Например, можно щёлкнуть по значку «построить сеть», а затем мышью провести линию от одного вывода компонента к другому, используя промежуточные щелчки для аккуратной трассировки с поворотами под углом 90° по единой сетке. Внутренняя логика программы должна не только отрисовывать визуальную линию, но и корректно определять электрическую связность, которую она представляет. Поэтому необходимо точно щёлкать по выводу компонента, чтобы начать или закончить линию, либо при соединении двух пересекающихся линий явно указывать на электрическое соединение сетей (часто с помощью специального компонента «точка»). К соединениям на принципиальной схеме часто можно добавить дополнительные сведения, например желаемую ширину дорожки на печатной плате для данного соединения или имя, присвоенное пользователем, например «входной сигнал».

Не все соединения на принципиальной схеме отображаются графически. Для повышения читаемости схем — как электронных, так и нарисованных вручную — часто используют условные обозначения, такие как символы земли или питания, а также объединение однотипных соединений в шины. Программы для создания схем обычно поддерживают эти условности. В некоторых случаях компоненты создаются с неявными (скрытыми) подключениями питания; в таких случаях эти соединения могут даже не отображаться на схеме, но будут экспортированы в программу для проектирования печатных плат. Однако, как правило, программы, предназначенные для начинающих разработчиков печатных плат, не требуют использования этих расширенных возможностей.

Поскольку выводам компонентов часто можно назначать атрибуты, такие как «вход питания», «выход», «вход» и т. д., некоторые программы ввода схем позволяют выполнять предварительную проверку проекта. Программа может отмечать соединения между двумя выходами, входы без подключений и т. п. Это далеко не так полезно и полно, как проверка правил проектирования (Design Rule Check), обсуждаемая ниже.

На схему можно добавлять произвольный текст, а в углу предусмотреть текстовый блок для указания даты, автора, версии, названия и другой информации, идентифицирующей схему.

### **СПИСКИ СОЕДИНЕНИЙ (NETLISTS)**

После размещения компонентов и выполнения соединений принципиальную схему можно распечатать, а также сгенерировать выходные файлы для программы трассировки печатных плат. Данные о соединениях и компонентах, необходимые для трассировки ПП, фиксируются в файле *списка соединений* (нетлиста). Процесс перехода от создания принципиальной схемы к трассировке ПП может быть тесно интегрирован, в этом случае пользователь может переключаться между схемой и ПП как между двумя представлениями одного проекта (что они и есть). Однако большинство программ для ввода схем генерируют отдельный файл списка соединений, который затем используется программой трассировки ПП, будь то интегрированный модуль или отдельная программа. Нетлист также может быть экспортирован во внешнюю программу моделирования схем или использоваться встроенным симулятором. (Подробнее см. в главе **Автоматизированное проектирование схем**.)

Файлы списков соединений часто представляют собой текстовые файлы, доступные для чтения человеком, и в большинстве случаев создать такой файл можно вручную. Однако для программы трассировки ПП нетлист обычно не обязателен; пользователь также может создать ПП непосредственно в процессе работы, добавляя компоненты и соединения по мере необходимости.

### **АННОТАЦИЯ И ВЕДОМОСТЬ МАТЕРИАЛОВ**

Ключевые особенности *прямой* и *обратной аннотации* проявляются на границе между созданием принципиальной схемы и трассировкой печатной платы. В процессе трассировки ПП нередко выявляются конструктивные недостатки проекта или становится очевидным, что внесение изменений в схему позволит упростить трассировку. Аналогично, промежуточный анализ схемы в процессе трассировки ПП может указать на необходимость внесения изменений. Если же правки вносятся непосредственно в ПП (например, переназначение выводов разъёма для упрощения трассировки), обратная аннотация позволяет перенести эти изменения «назад» в принципиальную схему. Данные о соединениях будут обновлены; однако пользователю, возможно, придётся вручную перерисовать соединительные линии, чтобы схема выглядела аккуратно. Аналогично, изменения, вносимые в схему после того, как ПП уже частично протрассирована, называются прямой аннотацией. Как и в случае обратной аннотации, при обновлении топологии соединений пользователю, скорее всего, потребуется вручную перераспределить дорожки. Ни прямая, ни обратная аннотация не являются обязательными, но они полезны для поддержания согласованности между схемой и ПП. Без их использования настоятельно рекомендуется вручную синхронизировать схему и ПП, чтобы избежать трудозатратных проблем на последующих этапах.

Наконец, исходные данные принципиальной схемы можно использовать для формирования *ведомости материалов* (BOM). В ведомости материалов перечисляются все компоненты схемы, как правило, упорядоченные по позиционным обозначениям, и её часто можно экспортировать для онлайн-заказа.

# 23.6.4 Характеристики печатных плат **КОНСТРУКЦИЯ ПЕЧАТНОЙ ПЛАТЫ**

Для понимания процесса проектирования печатных плат полезно знать основы их конструкции. На **рисунке 23.28** показана базовая структура печатной платы и некоторые её конструктивные элементы (рассматриваемые в последующих разделах). Диэлектрическая основа обеспечивает стабильную, изолирующую подложку с известными характеристиками (тепловыми, диэлектрическими и т. д.). Медь наносится на одну или обе стороны и селективно удаляется (обычно химическим способом), оставляя проводники печатной платы и контактные площадки. Контактные площадки служат точками подключения компонентов. Хотя электрическая связь является первостепенной, важно помнить, что припой и контактные площадки обеспечивают также механическую и тепловую связь. Контактные площадки могут иметь отверстия для монтажа компонентов со сквозными выводами или оставаться без отверстий для компонентов поверхностного монтажа.

Отдельный электрохимический процесс покрывает внутреннюю поверхность *металлизированных переходных отверстий* для обеспечения связи между верхними и нижними контактными площадками. Переходные отверстия, единственная цель которых — обеспечение электрической связи между слоями печатной платы, называются *переходными отверстиями (via)*, показанными на **рисунке 23.29**. Поскольку они не предназначены для размещения выводов компонентов, их размер отверстия и контактной площадки меньше.

![](_page_976_Picture_11.jpeg)

**Рисунок 23.29 —** *Переходное отверстие (via)* **обозначает металлизированное отверстие, соединяющее один слой платы с другим. Хотя двухслойные платы позволяют размещать компоненты с обеих сторон, на большинстве печатных плат существует основная сторона, называемая *монтажной стороной*, на которой размещается большинство компонентов, и *паяльная сторона*, на которой преобладают припаянные выводы и проводники. При необходимости высокой плотности компоновки компоненты поверхностного монтажа (а иногда и со сквозными выводами) размещают с обеих сторон, однако это значительно усложняет процесс.

Многослойные платы по своей сути представляют собой стопку из двух или более двухслойных плат, между которыми находятся изолирующие слои. Металлизированные переходные отверстия обеспечивают связь на каждом слое, а толщина диэлектрической основы пропорционально уменьшается, так что общая толщина всей многослойной платы примерно равна толщине обычной двухслойной платы. Переходные отверстия, соединяющие выбранные соседние медные слои без подключения всей стопки слоёв, называются «скрытыми» или «слепыми» переходными отверстиями и обычно требуются только для очень плотных компоновок. Многослойные платы обеспечивают значительно большую гибкость в разводке сигналов и <span id="page-977-0"></span>некоторые другие преимущества, такие как выделенные слои для распределения питания и заземления, но часто при значительном удорожании.

### **ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ К ИЗГОТОВЛЕНИЮ ПЕЧАТНЫХ ПЛАТ**

Если плату изготавливает не сам радиолюбитель, файлы ПП отправляют на *фирму-изготовитель печатных плат*. Наиболее важным вопросом для радиолюбителя может стать ценовая политика фирмы-изготовителя. На стоимость повлияют размер платы, количество экземпляров, сроки изготовления, число слоёв, количество и/или плотность отверстий, наличие масок пайки и шелкографии, минимальная ширина проводника и зазор, тип материала платы и толщина медного слоя. Ранее применявшийся для экономии вариант односторонней платы может не предлагаться в услугах с низкой стоимостью и малыми тиражами — двухслойная плата часто оказывается самым простым и надёжным решением. [Примечание: большинство спецификаций для заказа используют британские единицы измерения — дюймы и унции. Зарубежные фирмы-изготовители могут использовать как британские, так и метрические единицы, или только метрические. В данном тексте использованы британские единицы, так как они наиболее часто встречаются в радиолюбительской практике. — *Ред.*]

Вторым важным аспектом являются производственные возможности и варианты заказа. Они различаются в зависимости от тарифов и сроков изготовления, но обычно включают следующее:

*Материал платы и толщина* — FR-4 является наиболее популярным материалом для малосерийных печатных плат; он представляет собой огнестойкое тканое стекловолокно на эпоксидном связующем. Типовая толщина составляет 0,062 дюйма (1/16 дюйма), однако иногда доступны и более тонкие материалы. Также доступны гибкие ламинаты, но они дороже и требуют большего времени на изготовление. Существуют специальные ламинаты для СВЧ-применения или работы в условиях высоких температур.

*Толщина меди* — Выражается в унциях на квадратный фут. Типичные значения составляют 1–2 унции (1 унция соответствует толщине 0,0014 дюйма). Для малых тиражей другие значения могут быть недоступны по низкой цене. Внутренние слои многослойных плат могут быть тоньше — уточните, если это важно. Для большинства проектов можно смело закладывать минимум 1 унцию меди для двусторонних плат; при необходимости передачи больших токов ширину проводников соответствующим образом увеличивают.

*Количество слоёв* — Наиболее распространены двухслойные платы. Из-за технологии изготовления ПП количество медных слоёв всегда кратно двум. На заводах с ускоренным изготовлением обычно доступны только двух- или четырёхслойные платы. Платы с более чем двумя слоями всегда обходятся дороже и часто требуют больше времени на производство.

*Минимальный размер, количество и плотность отверстий* — Минимальный размер отверстия редко становится проблемой, но нестандартные конструкции с высокой плотностью отверстий или большим количеством разных диаметров могут повлечь дополнительные расходы. Обязательно учитывайте переходные отверстия (vias) при указании минимального размера. Некоторые фирмы-изготовители имеют строго определённый список поддерживаемых диаметров сверл. Обратите внимание: часто достаточно просто отредактировать файл сверления, чтобы сократить количество различных диаметров.

*Минимальная ширина проводника и зазор* — Эти два параметра часто имеют близкие значения. Большинство фирм-изготовителей без проблем изготавливают платы с шириной проводника не менее 0,010 дюйма, однако часто доступны и значения 0,008 и 0,006 дюйма, иногда за дополнительную плату.

*Минимальное кольцо вокруг отверстия* — Вокруг каждого металлизированного отверстия требуется минимальная ширина медного кольца, поскольку технологические процессы изготовления печатной платы имеют допуски. Это может указываться как отношение размера площадки к диаметру отверстия, но чаще — как ширина самого кольца.

*Зазоры от края платы* — Отверстия, площадки и проводники не должны располагаться слишком близко к краю платы.

*Контур платы и её тиражирование* — Могут быть предусмотрены опции для формирования контура платы в форме, отличной от прямоугольной, например, для размещения в конкретном корпусе или оптимизации компоновки. При заказе нескольких копий платы некоторые производители могут *панелировать* её, размещая несколько экземпляров на одной большой панели (что снижает стоимость каждого экземпляра). Эти экземпляры могут быть вырезаны на производстве или соединены небольшими перемычками для последующей сборки нескольких плат как единого блока.

*Оловянное покрытие* — После травления проводящих дорожек и сверления отверстий на открытые медные поверхности обычно наносится оловянное покрытие для обеспечения хорошей паяемости.

*Маска пайки* — Это защитное покрытие, устойчивое к расплавленному припою, наносимое после оловянного покрытия на обе стороны платы. Оно покрывает всё, кроме площадок для монтажа компонентов. Маска предотвращает замыкание расплавленного припоя между площадками и проводниками. Маска пайки предоставляется практически всеми производителями, за исключением сервисов с минимальным сроком изготовления. Наиболее распространён зелёный цвет, но могут быть доступны и другие варианты.

*Шелкография* — Это слой краски (обычно белого цвета) поверх маски пайки, на котором размещаются контуры компонентов, их обозначения и другие символы или текст. Может указываться минимальная ширина линии — если не указано иное, старайтесь избегать слишком тонких линий. Практически все производители, за исключением сервисов с минимальным сроком, предлагают шелкографию на одной или обеих сторонах печатной платы.

### 23.6.5 Элементы проектирования печатных плат

В принципиальной схеме могут не указываться конкретные корпуса деталей, а также ширина или длина соединений. Печатная плата, являясь физическим объектом, состоит из конкретных экземпляров компонентов (не просто «резистор», а, например, «осевой выводной резистор мощностью 1/4 Вт, смонтированный горизонтально») и дорожек — соединений между выводами компонентов с определённой шириной и зазором до других проводников. Прежде чем обсуждать процесс разводки, кратко рассмотрим особенности компонентов и соединений в печатной плате.

### **Дорожки**

Дорожки — второй основной элемент конструкции печатной платы: медные проводники, обеспечивающие электрическое соединение компонентов. Дорожки на ПП представляют собой просто плоские проводники — по сравнению с медным проводом эквивалентного сечения они не обладают какими-либо особыми свойствами. На частотах ВЧ/УКВ/СВЧ и для высокоскоростных цифровых сигналов дорожки ПП ведут себя как линии передачи, и эти свойства необходимо учитывать при проектировании, а также можно использовать их с выгодой.

На дорожки накладываются лишь немногие ограничения, помимо тех, что задаются производителем печатных плат (минимальная ширина, зазор и т. п.). Они создаются методом химического травления и могут иметь произвольную форму. Более того, на медных слоях можно наносить текст и символы, что бывает удобно, если не используется маркировочный слой (шелкография). Дорожки могут быть любой длины, меняться по ширине, включать изгибы или повороты и т. д. Однако большинство дорожек имеют постоянную ширину на всей своей длине (часто совпадающую с шириной других дорожек, несущих аналогичные сигналы), образуют аккуратные углы 45° или 90°, а на двухслойных платах обычно стараются прокладывать их горизонтально на стороне компонентов или вертикально на стороне пайки.

Те же соображения, которые учитываются при сборке схемы другими методами, применяются и к проектированию ПП: допустимый ток (ширина дорожки, толщина меди), рабочее напряжение (зазор до других проводников), помехи (экранирование, ограждение, близость к другим сигналам), импеданс цепей заземления и питания и т. д.

### 23.6.6 Компоновка печатной платы

После подготовки принципиальной схемы и списка соединений, а также определения всех параметров печатной платы можно приступать к непосредственной компоновке печатной платы.

#### **РАЗМЕР ПЛАТЫ И ЧИСЛО СЛОЁВ**

Первый этап компоновки печатной платы — создание её контура (габаритной формы), который должен учитывать не только размещение элементов схемы, но и дополнительные конструктивные особенности, например, монтажные отверстия. В макетных или единичных разработках плату обычно целесообразно сделать немного больше, чтобы оставить больше пространства между компонентами для удобства тестирования и отладки. (Некоторые недорогие или бесплатные коммерческие САПР для трассировки печатных плат накладывают ограничения на габариты платы и допустимое количество элементов.) Контур платы может задаваться в виде размера по умолчанию, который пользователь может изменить, или же его необходимо создавать вручную с нуля.

Как отмечалось выше, прямоугольная форма платы обычно является стандартной, однако многие производители печатных плат могут изготовить платы с более сложными контурами, включая криволинейные. Такие контуры вырезаются с достаточной точностью и могут сэкономить этап механической обработки, если плате требуется вырез или нестандартная форма для установки в конкретное место.

Хотя программа может не требовать определять количество слоёв печатной платы на самом начальном этапе, пользователю следует принять это решение как можно раньше, поскольку переход от двух слоёв к четырём или более существенно повлияет как на трассировку дорожек, так и на стоимость изготовления!

Для первого проекта рекомендуется начать с двухслойной платы для простой схемы, которую вы уже собрали и проверили. Это сократит количество принимаемых решений и исключит ряд неопределённостей из процесса проектирования.

### **РАЗМЕЩЕНИЕ КОМПОНЕНТОВ**

Грамотная расстановка компонентов — это уже половина успеха при трассировке печатной платы. Неудачное размещение потребует сложной прокладки дорожек и усложнит монтаж, тогда как правильная компоновка позволяет получить аккуратные и легко собираемые конструкции.

Первыми размещают монтажные отверстия или другие элементы с фиксированным положением. Обычно их добавляют с помощью специальной команды из палитры инструментов программы, а не как компоненты из библиотеки. Для отверстий, достаточных под винт №4 или №6, обычно достаточно; обязательно оставьте место вокруг них для головок винтов и гаек, а также для ключа или опорных стоек снизу. Это будут непроходные отверстия без контактных площадок (хотя производитель печатных плат может меднить все отверстия на плате независимо от требований).

В зависимости от используемого ПО и того, создавалась ли принципиальная схема, контур платы может уже содержать посадочные места всех компонентов (иногда они сгруппированы в один угол платы), а нетлист уже загружен. В этом случае компоненты можно размещать, перетаскивая их в нужные точки на плате. Большинство программ для проектирования печатных плат имеют функцию «паутинки» соединений, которая рисует прямые линии для каждого соединения из нетлиста. Это очень помогает при размещении, так как связи между компонентами становятся очевидными при их перемещении. (См. **Рисунок 23.31**) Однако соединения показываются до ближайшего контакта, имеющего эту электрическую связь; поэтому для таких компонентов, как развязывающие конденсаторы (которые часто должны находиться рядом с конкретным компонентом), «паутинка» будет тянуться к ближайшим контактам питания и земли, а не к тем, которые задумал конструктор. Их придётся редактировать вручную.

ПО для проектирования печатных плат может предлагать *автоматическую расстановку*, при которой компоненты изначально размещаются программой. Новичку определённо стоит поэкспериментировать и оценить работу этого инструмента, но для большинства проектов он вряд ли окажется полезным.

Печатные платы не обязательно располагать в точном соответствии со схемой, но при возможности компоненты следует размещать в логической последовательности, чтобы минимизировать длину дорожек в сигналном пути. Чувствительные компоненты могут потребовать изоляции или экранирования от других компонентов, а вопросы заземления и развязки должны быть проработаны, так же как и в случае с навесным монтажом.

Если печатная плата разрабатывается «по ходу» или на основе импортированного нетлиста, компоненты может потребоваться выбирать и размещать на плате вручную, используя библиотеки компонентов программы для проектирования ПП. Не весь софт для проектирования упрощает или ускоряет эту задачу — в частности, описание посадочных мест компонентов может быть запутанным. Использование сильно сокращённых отраслевых стандартов или не унифицированных систем обозначений часто вынуждает пользователя просматривать библиотеку компонентов, чтобы найти нужный тип. Резисторы, диоды и конденсаторы особенно подвержены нагромождению сложных для понимания вариантов. Одним из решений является открытие примера разводки ПП и просмотр того, какие элементы библиотеки использовал автор для резисторов, светодиодов и т. д. В этом случае программное обеспечение для разводки ПП, ориентированное на радиолюбителей, может оказаться предпочтительнее, поскольку в нём меньше вариантов, чем в профессиональных программах.

При размещении пользователь обнаружит, что различное ориентирование компонентов упрощает трассировку (например, за счёт минимизации количества пересекающихся дорожек или сокращения их длины). Компоненты обычно поворачивают с шагом 90°, хотя может быть доступна свободная rotation (произвольный угол поворота). Пользователю настоятельно рекомендуется сохранять одинаковое ориентирование однотипных элементов настолько, насколько это возможно. Смешивание положения вывода 1 в корпусах интегральных микросхем или случайное ориентирование конденсаторов, диодов и светодиодов создаёт риск трудоёмких проблем при монтаже и отладке, которые можно минимизировать за счёт последовательной и логичной компоновки.

Размещение и ориентация компонентов также влияют на удобство сборки готовой печатной платы. Например, оставляйте достаточно места для разъёмов (панелек), а также для вставки и извлечения интегральных микросхем. Компоненты с выступающими элементами, такие как потенциометры и переключатели, следует располагать так, чтобы обеспечить к ним доступ для регулировки. Любые компоненты, такие как разъёмы, переключатели или индикаторы (например, светодиоды), следует располагать тщательно, особенно если они должны выступать сквозь лицевую панель. Часто это потребует, чтобы компонент выступал за край ПП. (Следите за требуемым зазором между медными дорожками/площадками и краем ПП.)

Для компонентов следует наносить контур на слое шелкографии, отображающий габариты всего элемента — например, транзистор в корпусе TO-220, установленный вплотную к ПП, должен иметь контур, показывающий монтажное отверстие и габариты монтажного ушка. Пользователю также следует учитывать зазоры, необходимые для дополнительного крепежа при установке компонента, например гаек и болтов или радиаторов, — включая зазоры для ключей или других сборочных инструментов.

При проектировании старайтесь минимизировать механические нагрузки на печатную плату, так как они могут привести к образованию трещин в проводниках, отрыву контактных площадок или другим проблемам. Для таких компонентов, как разъёмы, переключатели и потенциометры, при возможности используйте монтажные отверстия или крепёжные ушки. Даже если конструкция допускает одностороннее исполнение, предпочтительнее применять двухслойные платы с металлизированными переходными отверстиями. Выводы компонентов, припаянные к металлизированным переходным отверстиям, обеспечивают значительно более прочное механическое соединение, чем в односторонних платах, где паяная площадка удерживается только за счёт сцепления меди с диэлектрической основой и легко отслаивается при чрезмерном нагреве или механическом воздействии.

При изготовлении опытного образца новой конструкции добавьте на плату несколько свободных контактных площадок для дополнительных компонентов (например, посадочные места для 16-контактного DIP-корпуса, площадки с шагом 0,4 дюйма для резисторов и других дискретных компонентов). Предусмотрите контрольные точки и соединения с общим проводом. В качестве них могут служить обычные площадки, к которым припаиваются обрезанные выводы: это обеспечит удобные точки для подключения зажимов «крокодил» или контроля сигналов.

Провода или кабели можно припаивать непосредственно к плате, но это неудобно при замене плат и не отличается высокой надёжностью. При возможности предпочтительнее использовать разъёмы, которые часто обеспечивают разгрузку от натяжения для провода или кабеля. Однако если провод припаивается к плате напрямую, следует предусмотреть рядом неметаллизированное отверстие, диаметр которого лишь чуть больше диаметра провода вместе с изоляцией. Провод можно провести со стороны пайки через это неметаллизированное отверстие, а затем припаять в обычное металлизированное переходное отверстие. Это обеспечит определённую степень разгрузки от натяжения, которую при необходимости можно усилить, нанеся каплю клея.

### **ТРАССИРОВКА ДОРОЖЕК**

После установки компонентов, монтажных отверстий и других элементов с фиксированным расположением, ограничивающих размещение компонентов и дорожек, можно приступить к *трассировке*. То есть к прокладке всех соединений между выводами без возникновения коротких замыканий.

Большинство программ для проектирования печатных плат позволяют размещать компоненты и дорожки по регулярной сетке, аналогично графическим редакторам. Может применяться две сетки — видимая сетка с крупным шагом и сетка привязки с мелким шагом, к которой будут выравниваться компоненты и другие объекты при размещении. Рекомендуется использовать сетку с шагом 0,1 или 0,050 дюйма для размещения компонентов и трассировать дорожки по сетке с шагом 0,025 дюйма. Хотя функцию привязки к сетке обычно можно отключить для точной подстройки положения, плата, трассированная по сетке, как правило, выглядит аккуратнее и её проще трассировать.

Дорожка начинается от вывода компонента и прокладывается к любому другому выводу, с которым должна быть соединена. Дорожки должны начинаться и заканчиваться в центре контактных площадок, а не у их края, чтобы соединение корректно записывалось в базу данных программы. Если загружен сетевой список (нетлист), большинство программ для ПКП отображают линию связи, показывающую прямое соединение между площадками. После завершения маршрутизации линия связи для этого соединения исчезает. Линия связи редко соответствует желаемому пути трассировки и часто указывает не на то конечное соединение. Например, при трассировке силовых дорожек пользователю следует руководствоваться здравым смыслом, а не слепо прокладывать извилистый маршрут, соединяющий выводы в случайном порядке. По этой причине хорошей практикой считается ранняя трассировка силовых цепей и земли.

Для высокоскоростных, высокочастотных и малошумящих схем потребуется дополнительная осторожность при трассировке. Как правило, дорожки, соединяющие цифровые схемы, такие как микропроцессоры и память, не должны пересекаться или находиться в непосредственной близости от дорожек, несущих аналоговые или ВЧ-сигналы. См. главу **ВЧ-техники** и предыдущие разделы данной главы, а также ссылки, приведённые в конце этого раздела.

Ручная трассировка — базовый навык проектирования печатных плат, независимо от того, используется ли автоматическая трассировка. В программном обеспечении этот процесс обычно максимально упрощён, поскольку трассировка занимает большую часть времени проектирования ПКП. Дорожка прокладывается на выбранном в данный момент медном слое. Для односторонней платы доступен только один слой для трассировки; для двухслойной платы дорожки могут размещаться как на стороне компонентов, так и на стороне пайки; для многослойных плат дорожки могут прокладываться на дополнительных внутренних слоях. Часто одной клавишей можно переключить активный медный слой (иногда с автоматической вставкой переходного отверстия, если маршрут ещё не завершён). Дорожка рисуется прямыми участками и заканчивается на целевом выводе. При трассировке обычно избегают углов 90° — стандартом является пара углов 45°. **Рисунок 23.32** показывает примеры дорожек.

На двусторонних платах принято располагать дорожки на одной стороне преимущественно горизонтально, а на другой — вертикально. Если дорожке необходимо пройти преимущественно по вертикали, её прокладывают на стороне с вертикальными дорожками, а для завершения горизонтального участка используют переходное отверстие (via).

Для упрощения испытаний и отладки наиболее удобно прокладывать большинство дорожек на нижней (паяльной) стороне платы: дорожки на стороне установки компонентов часто проходят под микросхемами или другими деталями, что затрудняет их визуальный контроль и доступ. Часто гораздо нагляднее соединять соседние выводы микросхем или разъёмов, прокладывая дорожку, которая выходит из одного контакта, отходит от микросхемы или разъёма, а затем возвращается к соседнему контакту. Это позволяет чётко видеть, что на собранной плате соединение не представляет собой перемычку из припоя (solder bridge), которой выглядело бы прямое соединение двух контактов.

Может случиться так, что ни переходные отверстия, ни извилистые трассы не позволят завершить соединение. Единственным оставшимся инструментом для конструктора ПП является перемычка (jumper) — провод, который добавляется как компонент при монтаже исключительно для соединения двух точек на плате. Перемычки чаще всего применяются на односторонних платах; при относительно коротком «перекиде» можно использовать провод без изоляции. Перемычки обычно выполняются в виде прямых линий и могут быть горизонтальными или вертикальными. На профессиональных серийных ПП в качестве перемычек используют машинно-вставляемые нуль-омные резисторы. Перемычки на двусторонних платах обычно воспринимаются не слишком благосклонно, однако это вопрос эстетики и эффективности монтажа, а не функциональности.

Многослойные платы, безусловно, предоставляют дополнительные возможности трассировки, но и здесь рекомендуется на каждом слое придерживаться доминирующего направления прокладки (вертикального или горизонтального), поскольку смешивание направлений часто усложняет трассировку. Однако нередко один или два внутренних слоя выделяют под линии питания и заземления, а не используют исключительно для сигнальных трасс. Это позволяет прокладывать силовые цепи с минимальным сопротивлением и оставляет сигнальные дорожки на сторонах установки компонентов и пайки, где их удобно измерить щупом или при необходимости изменить. Изменять трассы на внутренних слоях, разумеется, гораздо сложнее!

Прежде чем проложить слишком много дорожек, полезно выполнить *Проверку правил проектирования (DRC)* для платы. (См. раздел «Проверка правил проектирования» ниже.) При раннем и регулярном применении DRC позволяет выявить проблемные зоны в тот момент, когда их проще всего исправить. Например, выбранная ширина дорожки может обеспечивать недостаточный зазор при прохождении между двумя контактами микросхемы.

Некоторые пакеты для проектирования печатных плат предлагают возможность *автоматической трассировки* (autorouter), при которой программа использует данные о компонентах и соединениях из спецификации (нетлиста) и пытается проложить дорожки автоматически. В определённых ситуациях эти инструменты действительно экономят время, но относиться к ним следует с осторожностью. Автопрокладчики хорошо справляются с задачей трассировки для заданной платы, но простое корректное соединение всех выводов ещё не гарантирует качественного дизайна. Дорожки, несущие критические сигналы, могут прокладываться по «зашумлённым» маршрутам; компоненты, которые должны иметь короткие соединения с минимальным сопротивлением, могут оказаться соединёнными длинными дорожками, и так далее. Более продвинутые автопрокладчики могут принимать обширные списки «подсказок» для минимизации этих проблем. Для новичков время, затраченное на передачу этой информации автопрокладчику, скорее всего, будет лучше потрачено на ручную трассировку дорожек.

Если используется автопрокладчик, как минимум критические соединения должны прокладываться вручную. К ним относятся чувствительные сигналы, соединения, длину которых следует минимизировать, а также часто линии питания и заземления (как из-за требований к подавлению радиочастотных помех, так и из-за необходимости соблюдения ширины дорожек). Ещё лучше — развить чувство того, как выглядит качественная разводка платы (это придёт с практикой и анализом хорошо спроектированных плат), и научиться определять, на каком этапе автопрокладчик можно «отпустить на волю» для завершения задачи трассировки.

### **ШИРИНА И РАССТОЯНИЕ МЕЖДУ ДОРОЖКАМИ**

Все дорожки будут иметь определённую ширину — это может быть ширина по умолчанию, последняя выбранная ширина или значение, указанное в нетлисте (спецификации соединений). Может возникнуть соблазн проложить все сигнальные дорожки, кроме силовых, самой тонкой шириной, доступной на производстве печатных плат (0,008 дюйма или меньше), поскольку это обеспечивает наибольшую плотность трассировки и упрощает её выполнение. Более правильным подходом к проектированию является использование более широких дорожек, чтобы избежать трудно обнаруживаемого растрескивания и повысить надёжность платы. Более распространённые дорожки шириной 0,012 дюйма можно прокладывать параллельно с шагом сетки 0,025 дюйма, и они могут проходить между многими контактными площадками с шагом 0,1 дюйма. Более широкие дорожки упростят самостоятельное изготовление платы, хотя точный используемый процесс (ЧПУ-фрезеровка, химическое травление и т. д.) будет ограничивать разрешающую способность. Обратите внимание, что на участках прохождения между контактными площадками микросхем или разъёмов возможно «сужение» дорожек: то есть стандартная широкая дорожка подходит вплотную к узкому зазору между площадками, проходит между ними с уменьшенной шириной, а затем снова расширяется до исходной. Для большинства сигналов мало смысла использовать дорожки шире примерно 0,030 дюйма (см. **Таблицу 23.5**), но ширина силовых и заземляющих дорожек должна соответствовать протекающему через них току.

Все дорожки обладают сопротивлением, и это сопротивление зависит от площади их поперечного сечения (ширина, умноженная на толщину) и длины. Это сопротивление преобразует электрическую мощность в тепло. Если выделяемое тепло превысит относительно высокий порог, дорожка превратится в довольно дорогой и трудноремонтозаменимый предохранитель.

Ширину дорожки следует выбирать так, чтобы при наихудшем ожидаемом токе повышение температуры ограничивалось заданным порогом, часто 10 °C. На практике силовые дорожки (особенно заземляющие) часто делают максимально широкими в пределах технологических возможностей, чтобы снизить сопротивление, и их ширина значительно превышает ту, что требуется только по критерию ограничения нагрева.

В **Таблице 23.5** обобщены максимальные токи для внешних (со стороны компонентов и пайки) и внутренних дорожек для некоторых распространённых ширин. Внутренние дорожки (на внутренних слоях многослойных плат) могут пропускать только около половины тока по сравнению с внешними дорожками той же ширины, поскольку внутренние слои не рассеивают тепло в окружающий воздух, как внешние. (Обратите внимание, что ширина дорожек иногда также выражается в «милах». 1 мил = 0,001 дюйма; это сокращение от «milli-inch», а не миллиметр!)

Для эффективной ширины дорожки нет верхнего предела. Часто большие участки печатной платы оставляют сплошной медной заливкой. Такие площади *заливки медью* могут выполнять функцию заземления, теплоотвода или просто упрощать изготовление платы (особенно самодельной). Не рекомендуется размещать отверстие под компонент в центре сплошной медной заливки — медь является очень эффективным теплоотводом при пайке. Вместо этого вокруг паяльной площадки наносят рисунок в виде «колеса с спицами», известный как **тепловое ответвление** (thermal relief), которое иногда формируется автоматически. Оно обеспечивает хорошее электрическое соединение, но снижает теплоотвод. Часто площади заливки медью задают с помощью полигона, и заливка автоматически обтекает площадки и дорожки в этой области, но может приводить к появлению изолированных островков меди.

На практике большинство плат имеют только две или, возможно, три различные ширины дорожек: узкие для сигнальных линий и более широкие для цепей питания (обычно с заметным запасом).

Ещё одно замечание по ширине дорожек: переходные отверстия обычно имеют один размер (то есть малый), но для создания соединений с низким сопротивлением между слоями можно использовать несколько отверстий. Размещать их так, чтобы их площадки не касались друг друга, — хорошее решение; в этом случае площадки замыкаются накоротко на верхнем и нижнем слоях.

На трассировку также влияет напряжение: вместо увеличения ширины дорожки для высоких напряжений следует увеличивать воздушный зазор между дорожкой и другими участками меди. Стандарт IPC-2221 требует зазора 0,024 дюйма для дорожек с напряжением 31–150 В (пиковым) и 0,050 дюйма для дорожек с напряжением 151–300 В (пиковым); это требования для внешних дорожек без покрытия. (При нанесении соответствующего полимерного покрытия лаком-фоторезистом зазоры составляют 0,006 дюйма для 31–100 В и 0,016 дюйма для 101–300 В. Для внутренних дорожек требования к зазорам также снижены.) Однако полный разбор вопросов безопасности (и нормативных требований) при прокладке высоковольтных цепей выходит за рамки данного краткого обзора, поэтому рекомендуется ознакомиться со стандартами UL или IPC.

### **ШЛЮКОГРАФИЯ И ПАЯЛЬНАЯ МАСКА**

Слой шелкографии (или «шелк») содержит текст и графику, которые будут нанесены на верхнюю сторону платы, как показано на **рис. 23.33**. Для компонентов, как правило, на слое шелкографии автоматически отображаются такие элементы, как позиционные обозначения и номиналы, однако остальные элементы необходимо создавать и размещать вручную. К распространённым элементам шелкографии относятся: название схемы, дата, версия, имя разработчика (и позывной), название компании, требования к питанию (напряжение, ток и номинал предохранителя), подписи для подключений (напр., «Вход микрофона»), предупреждения и примечания, подписи для регулировок и переключателей. Сплошной белый прямоугольник на слое шелкографии может служить удобным полем для нанесения серийного номера или тестовой информации.

Производитель печатных плат укажет минимальную ширину линий шелкографии, включая ширину шрифта текста. Текст и графику можно размещать в любом месте паяльной маски, но не на контактных площадках и отверстиях.

### **ПРОВЕРКА ПРАВИЛ ПРОЕКТИРОВАНИЯ**

Если из программы построения принципиальных схем была получена сетевая диаграмма (нетлист), можно выполнить *проверку правил проектирования* (*DRC*) топологии платы. Программа для проектирования печатных плат применит к плате заданный список правил, проверяя, что все соединения из нетлиста выполнены, что между всеми дорожками соблюдены достаточные зазоры, и т. д. Эти правила можно настроить в соответствии с требованиями конкретного производителя печатных плат. Как отмечалось выше, полезно запускать проверку DRC даже до завершения трассировки всех дорожек — это поможет выявить проблемы с зазорами или иные недостатки, которые могут потребовать существенной перетрассировки или изменения подхода.

Если пользователь дождётся завершения всей трассировки перед запуском DRC, список нарушений может показаться внушительным. Однако часто бывает так, что многие (если не все) нарушения указывают на проблемы, которые могут помешать корректной работе платы. При возможности все нарушения DRC следует устранить до передачи платы в изготовление.

### **ОБЗОР МАКЕТА (LAYOUT REVIEW)**

После успешного прохождения DRC (проверки правил проектирования) корректность электрических соединений и базовые требования к технологичности изготовления, как правило, уже выполнены. Однако макет может выиграть от дополнительного прохода проверки. Отключите отображение всех слоёв, кроме одного медного, и внимательно осмотрите дорожки — часто упрощения в трассировке становятся очевидными без визуального шума от других медных слоёв. Например, дорожку можно сместить, чтобы она не проходила между двумя близко расположенными выводами. Плотные группы дорожек можно развести на большее расстояние. Может появиться возможность сократить количество переходных отверстий, прокладывая дорожки преимущественно на одном слое, даже если это потребует изменения направления трассы как по вертикали, так и по горизонтали. Повторите эту процедуру для всех медных слоёв.

Также проверьте конструктивные особенности платы, в частности близость дорожек к крепёжным элементам. Если на прототипе печатной платы отсутствует паяльная маска, дорожки, проходящие под компонентами в токопроводящем корпусе (например, кварцевыми резонаторами) или слишком близко к крепёжной фурнитуре, могут образовать короткое замыкание. Необходимо предусмотреть изоляцию или перетрассировать дорожку.

После завершения проектирования печатной платы можно сгенерировать полный комплект файлов описания конструкции для её изготовления. К ним относятся:

*Слои меди* — по одному файлу на каждый медный слой. Эти файлы известны как *файлы Gerber* и изначально представляли собой текстовые файлы с командами для управления *фотоплоттером*. Компания Gerber была ведущим производителем фотоплоттеров — устройств, перемещавших источник света переменной ширины (апертур) из одной точки в другую для построения рисунка на фотоплёнке. Хотя фотоплоттеры были заменены цифровыми технологиями, формат Gerber был стандартизирован как RS-274X и используется повсеместно, за исключением ПО для проектирования ПП, привязанных к конкретному производителю. Формат RS-274X родственен RS-274D («G-код»), используемому операторами станков с ЧПУ для программирования оборудования, но представляет собой *аддитивное* описание (по сути, команду «нанести медь сюда»), а не описание перемещений инструмента для удаления материала. Поэтому при использовании ЧПУ для изготовления ПП путём механического удаления меди требуется программа для преобразования между форматами Gerber и G-код.

*Файл сверления* — файл, содержащий координаты и диаметры сверления для всех отверстий (как металлизированных, так и нема металлизированных). Также называется *NC*-файлом или файлом *Excellon*. Некоторые производители печатных плат могут требовать определённый формат координат, но обычно эти параметры доступны для настройки в программе для проектирования ПП. Для одной ПП требуется только один файл сверления, поскольку отверстия сверлятся с одной стороны. (Для экзотических решений, таких как скрытые переходные отверстия, потребуется дополнительная информация.) Как и апертуры в RS-274X, файл сверления обычно содержит таблицу сверлений.

*Слой шелкографии* — также в формате RS-274. Некоторые производители могут наносить шелкографию с обеих сторон платы, для чего потребуется два файла.

*Паяльная маска* — файл паяльной маски используется производителем для создания защитного лака. Требуется по одному файлу на каждую сторону платы.

Для просмотра файлов Gerber с трассировкой можно использовать программы предварительного просмотра, такие как *Gerbv* (**gerbv.gpleda.org**, с открытым исходным кодом, *Linux*, Mac OS X) или *GC-Prevue* (**www.graphicode.com**, *Windows*). Это хорошая проверка: плата будет изготавливаться именно по Gerber-файлам, а не по исходному проекту в программе для проектирования ПП. Предпросмотрщики Gerber позволяют импортировать слои меди, слой шелкографии и файл сверления для проверки их соответствия и корректности.

Любые из слоёв обычно можно распечатать непосредственно в программе для проектирования ПП (и/или в программе предпросмотра Gerber) для справки и дальнейшего контроля.

Помимо файлов для изготовления ПП, программы для трассировки могут генерировать монтажные чертежи, а в некоторых случаях — трёхмерные представления внешнего вида собранной платы. Это может быть полезно для документации, а также для проверки механических параметров, таких как габаритные зазоры.

Отправка файлов на производство печатных плат или на фабрику печатных плат и заказ самих плат подробно описаны на сайте производителя, либо менеджер службы поддержки поможет вам разобраться в этом процессе. Некоторые компании принимают наборы файлов на CD-ROM и могут также предложить услугу проверки проекта для новых клиентов или на платной основе.
