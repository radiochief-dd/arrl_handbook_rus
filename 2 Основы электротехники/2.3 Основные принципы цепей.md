### 2.3 Основные принципы электрических цепей

Цепи состоят из *узлов* и *ветвей*. Узел — это любая точка цепи, в которой ток может разделяться между проводящими путями. Например, в параллельной цепи на **рисунке 2.5A** узел обозначен точкой на принципиальной схеме. Ветвь — любой уникальный путь протекания тока между узлами. Последовательность ветвей, образующих замкнутый путь для тока (например, последовательная цепь на рисунке 2.1A), называется *конуром*.

Очень мало реальных цепей настолько просты, как показано на рисунке 2.1. Однако все цепи, независимо от их сложности, состоят из комбинаций этих последовательных и параллельных цепей. Теперь мы воспользуемся этими простыми схемами с резисторами и источниками питания для иллюстрации двух фундаментальных правил для напряжения и тока, известных как *законы Кирхгофа*.

### 2.3.1 Закон Кирхгофа для токов

Закон Кирхгофа для токов (ЗКТ) гласит: «Сумма всех токов, входящих в узел, и всех токов, выходящих из него, равна нулю». Математически ЗКТ записывается следующим образом:

$$(I_{in1} + I_{in2} + ...) - (I_{out1} + I_{out2} + ...) = 0$$

Многоточие означает, что в уравнение может быть включено любое необходимое количество токов.

Эквивалентная формулировка ЗКТ заключается в том, что сумма всех токов, входящих в узел, должна равняться сумме всех токов, выходящих из него:

$$(I_{in1} + I_{in2} + ...) = (I_{out1} + I_{out2} + ...)$$

Закон Кирхгофа для токов проиллюстрирован следующим примером. Предположим, что три резистора (R1 = 5,0 кОм, R2 = 20,0 кОм и R3 = 8,0 кОм) соединены параллельно, как показано на рисунке 2.5А. Ко всем трём резисторам приложено одинаковое напряжение — 250 В. Ток через R1 обозначен как I1, ток через R2 — как I2, а ток через R3 — как I3.

Токи в каждом из резисторов можно найти по закону Ома, как показано ниже. Для удобства сопротивление можно указывать в кОм, тогда ток будет выражен в миллиамперах.

$$I1 = \frac{E}{R1} = \frac{250 \text{ В}}{5,0 \text{ кОм}} = 50,0 \text{ мА}$$

$$I2 = \frac{E}{R2} = \frac{250 \text{ В}}{20,0 \text{ кОм}} = 12,5 \text{ мА}$$

$$I3 = \frac{E}{R3} = \frac{250 \text{ В}}{8,0 \text{ кОм}} = 31,2 \text{ мА}$$

![](_page_46_Figure_27.jpeg)

Рисунок 2.5 — Пример параллельного (А) и последовательного (Б) соединения резисторов. В последовательных цепях ток через все компоненты одинаков, а напряжения складываются. В параллельных цепях напряжение на всех компонентах одинаково, а сумма токов, входящих в узлы цепи, равна сумме токов, выходящих из них. На части С показано, как рассчитать эквивалентные значения для последовательных и параллельных комбинаций.

<span id="page-47-0"></span>Обратите внимание, что токи в ветвях обратно пропорциональны сопротивлениям. Сопротивление резистора 20 кОм в четыре раза больше, чем у резистора 5 кОм, а протекающий через него ток в четыре раза меньше. Если сопротивление одного резистора в два раза больше другого, то при параллельном соединении ток через него будет вдвое меньше.

Используя уравновешенную форму ЗКТ, найдём ток, который должен обеспечивать источник питания (батарея):

$$I_{Batt} = I1 + I2 + I3$$

$$I_{Batt} = 50,0 \text{ мА} + 12,5 \text{ мА} + 31,2 \text{ мА}$$

$$I_{Batt} = 93,7 \text{ мА}$$

### 2.3.2 Резисторы, соединённые параллельно

В цепи с параллельным соединением резисторов их можно заменить одним *эквивалентным* сопротивлением, равным результату параллельного соединения всех резисторов. В параллельной цепи эквивалентное сопротивление всегда меньше наименьшего из включённых сопротивлений. Это связано с тем, что общий ток всегда больше тока через любой отдельный резистор. Формула для расчёта эквивалентного сопротивления при параллельном соединении имеет вид:

$$R_{EQUIV} = \frac{1}{\frac{1}{R1} + \frac{1}{R2} + \frac{1}{R3} + \frac{1}{R4} \dots}$$

где многоточие указывает на то, что любым количеством параллельных резисторов можно объединить по тому же принципу. Это уравнение часто называют «суммой обратных величин». На рисунке 2.5С показано общее правило для принципиальной схемы.

В примере предыдущего раздела эквивалентное сопротивление равно:

$$R = \frac{1}{\frac{1}{5 \text{ k}\Omega} + \frac{1}{20 \text{ k}\Omega} + \frac{1}{8 \text{ k}\Omega}} = 2.67 \text{ k}\Omega$$

Часто используется обозначение «//» (две косые черты), означающее «включён параллельно». С использованием этого обозначения предыдущий пример записывается как `5.0 k $\Omega$ // 20 k $\Omega$ // 8.0 k $\Omega$`.

Если все параллельно соединённые резисторы имеют одинаковое номинальное значение, эквивалентное сопротивление находится делением этого значения на количество резисторов $N$. Например, для пяти параллельно включённых резисторов по 50 Ом эквивалентное сопротивление составит $R=50 / N=50 / 5=10 \ \Omega$.

Для случая параллельного соединения только двух резисторов (что встречается очень часто) формулу можно упростить до гораздо более простой (и удобной для запоминания):

$$R_{EQUIV} = \frac{R1 \times R2}{R1 + R2}$$

Пример: Каково общее сопротивление, если резистор 500 Ом подключён параллельно резистору на 1200 Ом?

$$R = \frac{R1 \times R2}{R1 + R2} = \frac{500 \ \Omega \times 1200 \ \Omega}{500 \ \Omega + 1200 \ \Omega}$$

$$R = \frac{600000 \Omega^2}{1700 \Omega} = 353 \Omega$$

Используя это уравнение, любое количество параллельных резисторов можно объединять попарно, пока все они не будут сведены к одному эквивалентному сопротивлению. Этот способ немного удобнее, чем применение общей формулы «суммы обратных величин» для преобразования за один шаг.

Другое полезное уравнение позволяет найти значение параллельного резистора $R_{PAR}$, которое при включении между теми же узлами, что и известный резистор $R_1$, даёт требуемое эквивалентное сопротивление $R_{DES}$:

$$R_{PAR} = \frac{R_1 R_{DES}}{R_1 - R_{DES}}$$

Например, какое значение резистора, включённого параллельно резистору на 10 кОм, обеспечит эквивалентное сопротивление 3 кОм?

$$R_{PAR} = \frac{10 \text{ k}\Omega \times 3 \text{ k}\Omega}{10 \text{ k}\Omega - 3 \text{ k}\Omega} = 4.28 \text{ k}\Omega$$

В стандартном ряду сопротивлений с допуском 5 % ближайшим доступным номиналом является 4,3 кОм.

### 2.3.3 Закон Кирхгофа для напряжений

Закон Кирхгофа для напряжений (ЗКН) гласит: «Сумма напряжений в замкнутом контуре равна нулю». Если закон Кирхгофа для токов (ЗКТ) интуитивно понятен, то ЗКН воспринимается сложнее. В цепи на рис. 2.5Б ЗКН требует, чтобы напряжение батареи точно уравновешивалось суммой напряжений на трёх резисторах схемы. Если бы этого не происходило, «лишнее» напряжение создавало бы бесконечный ток при отсутствии ограничивающего сопротивления, подобно тому как ЗКТ предотвращает «накопление» заряда в узле цепи. Математически ЗКН записывается так:

$$E_1 + E_2 + E_3 + ... = 0$$

где каждое $E$ обозначает напряжение, возникающее на участке контура при протекании тока.

Это лучше всего иллюстрируется примером. Хотя ток через все три резистора в предыдущем примере одинаков, полное напряжение распределяется между ними так же, как ток делится между параллельно соединёнными резисторами. Напряжение на каждом резисторе (так называемое *падение напряжения*) определяется законом Ома. (Напряжение на сопротивлении часто называют «падением» или «I·R-падением», поскольку значение напряжения уменьшается на величину $E = I \times R$.)

Для применения ЗКН обычно принимают следующее правило знаков: если ток течёт *в* более положительный вывод компонента, напряжение считается положительным в уравнении ЗКН. Если ток течёт *из* положительного вывода, напряжение считается отрицательным. Положительные напряжения соответствуют компонентам, потребляющим («поглощающим») мощность, например резисторам. Отрицательные напряжения соответствуют компонентам, вырабатывающим («отдающим») мощность, таким как батареи. Это позволяет записать уравнение ЗКН в сбалансированной форме:

$$(E_{\text{source}1} + E_{\text{source}2} + ...) = (E_{\sin k1} + E_{\sin k2} + ...)$$

В этой форме все напряжения считаются положительными, при этом источники мощности (ток течёт *из* более положительного вывода) помещаются в одну часть уравнения, а потребители мощности (ток течёт *в* более положительный вывод) — в другую.

Обратите внимание: для ЗКН не имеет значения абсолютное напряжение вывода компонента относительно «земли», важно лишь, какой вывод компонента более положителен по отношению к другому. Если один вывод резистора находится под потенциалом +1000 В, а другой — под +998 В, ток, входящий в первый вывод и выходящий из второго, испытает падение напряжения +2 В. Аналогично, ток от батареи 9 В, у которой положительный вывод имеет потенциал -100 В, а отрицательный — -108,5 В, для ЗКН всё равно будет считаться источником напряжением 8,5 В. Также следует отметить, что ток может течь *в* положительный вывод батареи (например, при зарядке), превращая её в потребитель мощности, как и резистор.

Приведём пример, иллюстрирующий работу ЗКН: на рис. 2.5Б, если напряжение на R1 равно E1, на R2 — E2, а на R3 — E3, то:

$$-250 + I \times R1 + I \times R2 + I \times R3 = 0$$

Это уравнение можно упростить до вида:

$$-250 + I (R1 + R2 + R3) =$$
  
 $-250 + I (33000 \Omega) = 0$

При решении относительно $I$ получаем: $I = 250/33000 = 0,00758\ \text{А} = 7,58\ \text{мА}$. Это позволяет вычислить значение напряжения на каждом резисторе:

$$E1 = I \times R1 = 0.00758 \text{ A} \times 5000 \Omega = 37.9 \text{ V}$$

$$E2 = I \times R2 = 0.00758 \text{ A} \times 20000 \Omega = 152 \text{ V}$$

$$E3 = I \times R3 = 0.00758 \text{ A} \times 000 \Omega = 60.6 \text{ V}$$

Проверка подтверждает, что сумма напряжений E1, E2 и E3 действительно равна напряжению батареи 250 В (при пренебрежении погрешностями округления):

$$E_{TOTAL} = E1 + E2 + E3$$

$$E_{TOTAL} = 37.9 \text{ V} + 152 \text{ V} + 60.6 \text{ V}$$

$$E_{TOTAL} = 250 \text{ V}$$

### 2.3.4 Последовательное соединение резисторов

В предыдущем примере было показано, что в цепи с несколькими резисторами, включёнными последовательно, эквивалентное сопротивление всей цепи равно сумме отдельных сопротивлений. Если они обозначены как $R_1$, $R_2$, $R_3$ и т. д., то:

$$R_{\text{ЭКВ}} = R_1 + R_2 + R_3 + R_4 \dots$$

На принципиальной схеме (рис. 2.5В) приведено общее правило для такого соединения.

Пример: Предположим, что три резистора подключены к источнику напряжения согласно рис. 2.5Б. Напряжение составляет 250 В, $R_1 = 5{,}0$ кОм, $R_2 = 20{,}0$ кОм, а $R_3 = 8{,}0$ кОм. Тогда эквивалентное сопротивление равно:

$$R_{\text{ЭКВ}} = R_1 + R_2 + R_3$$
$$R_{\text{ЭКВ}} = 5{,}0 \text{ кОм} + 20{,}0 \text{ кОм} + 8{,}0 \text{ кОм}$$
$$R_{\text{ЭКВ}} = 33{,}0 \text{ кОм}$$

Ток в цепи равен:
$$I = \frac{V}{R_{\text{ЭКВ}}} = \frac{250 \text{ В}}{33{,}0 \text{ кОм}} = 7{,}58 \text{ мА}$$

---
*Примечание переводчика:* 
- Исправлены опечатки в индексах формул (`EOUIV`/`FOUIV` → `_ЭКВ`) и в обозначении единицы сопротивления (`kO` → `\text{кОм}`).
- Десятичные разделители приведены к ГОСТу (запятая).
- Обозначения рисунков адаптированы к русской типографской традиции (латинские буквы заменены на кириллические `Б`, `В`).

### 2.3.5 Проводимости при последовательном и параллельном соединении

Поскольку проводимость является величиной, обратной сопротивлению ($G = 1/R$), формулы для соединения резисторов последовательно и параллельно можно преобразовать для использования проводимости, заменив $R$ на $1/G$. Проводимости при последовательном соединении объединяются аналогично резисторам при параллельном соединении:

$$G = \frac{1}{\frac{1}{G1} + \frac{1}{G2} + \frac{1}{G3} + \frac{1}{G4} \dots}$$

а две проводимости, включённые последовательно, можно совместить аналогично двум резисторам при параллельном соединении:

$$G_{EQUIV} = \frac{G1 \times G2}{G1 + G2}$$

Проводимости при параллельном соединении объединяются аналогично сопротивлениям при последовательном соединении:

$$G_{TOTAL} = G1 + G2 + G3 + G4 ...$$

Это также показывает, что при большом количестве параллельно соединённых сопротивлений переход к проводимостям может несколько упростить вычисления.

### 2.3.6 Эквивалентные схемы

Схема может содержать сопротивления как при параллельном, так и при последовательном соединении, как показано на рис. 2.6А. В

![](_page_48_Picture_20.jpeg)

Рис. 2.6 — На рисунке А приведен пример резисторов в смешанном (последовательно-параллельном) соединении. Эквивалентная схема показана на Б.

Для анализа поведения такой схемы создаются эквивалентные цепи, которые формируются и объединяются с помощью формул для соединения резисторов последовательно и параллельно. Каждую отдельную группу резисторов (последовательное или параллельное соединение) можно заменить одним эквивалентным резистором. Полученные комбинации можно упрощать дальше до тех пор, пока не останется всего один резистор.

Самый простой процесс начинается с объединения любых двух резисторов в один эквивалентный резистор по формулам для последовательного или параллельного соединения сопротивлений. Затем полученное эквивалентное сопротивление объединяется с любым оставшимся одиночным резистором, образуя новое эквивалентное сопротивление. Процесс объединения эквивалентного сопротивления с одним резистором повторяется до тех пор, пока все сопротивления не будут сведены к одному эквивалентному сопротивлению. Например, чтобы найти эквивалентное сопротивление для схемы на рис. 2.5А: объединим R2 и R3, создав один эквивалентный резистор $R_{\rm EQ}$, значение которого равно параллельному соединению R2 и R3.

$$R_{EQ} = \frac{R2 \times R3}{R2 + R3} = \frac{20000 \ \Omega \times 8000 \ \Omega}{20000 \ \Omega + 8000 \ \Omega}$$

$$= \frac{1.60 \times 10^8 \ \Omega^2}{28000 \ \Omega} = 5710 \ \Omega = 5.71 \ k\Omega$$

Это сопротивление включено последовательно с R1, образуя простую цепь последовательного соединения, как показано на рис. 2.5Б. Эти два сопротивления затем можно объединить в одно эквивалентное сопротивление $R_{TO-TAL}$ для всей цепи:

$$R_{TOTAL} = R1 + R_{EO} = 5.0 \text{ k}\Omega + 5.71 \text{ k}\Omega$$

$$R_{TOTAL} = 10.71 \text{ k}\Omega$$

![](_page_48_Picture_29.jpeg)

Рис. 2.7 — Источники напряжения для постоянного (A) и переменного (B) тока, а также источники тока (C) являются примерами идеальных источников энергии.

Ток батареи тогда равен:

$$I = \frac{E}{R} = \frac{250 \text{ V}}{10.71 \text{kO}} = 23.3 \text{ mA}$$

Падения напряжения на R1 и R<sub>EO</sub> составляют:

$$E1 = I \times R1 = 23.3 \text{ mA} \times 5.0 \text{ k}\Omega = 117 \text{ V}$$

$$E2 = I \times R_{EQ} = 23.3 \text{ mA} \times 5.71 \text{ k}\Omega = 133 \text{ V}$$

Сумма этих двух падений напряжения равна 250 В, как описано законом Кирхгофа для напряжений. Напряжение E2 приложено к обоим резисторам R2 и R3, поэтому

$$I2 = \frac{E2}{R2} = \frac{133 \text{ V}}{20.0 \text{ k}\Omega} = 6.65 \text{ mA}$$

$$I3 = \frac{E3}{R3} = \frac{133 \text{ V}}{8.0 \text{ k}\Omega} = 16.6 \text{ mA}$$

где
I2 = ток через R2 и
I3 = ток через R3.

Сумма токов I2 и I3 равна 23,3 мА, что соответствует закону Кирхгофа для токов.

### 2.3.7 Источники напряжения и тока

При проектировании цепей и описании поведения электронных компонентов часто удобно использовать *идеальные источники*. Наиболее распространёнными типами идеальных источников являются *источник напряжения* и *источник тока*, обозначения которых приведены на **рис. 2.7**. Эти источники считаются идеальными, поскольку независимо от того, какая цепь подключена к их выводам, они продолжают отдавать заданное значение напряжения или тока. Практические источники напряжения и тока могут приближённо воспроизводить поведение идеального источника в определённых диапазонах, но ограничены по отдаваемой мощности, поэтому при чрезмерной нагрузке их выходные параметры снижаются.

<span id="page-49-0"></span>Источники напряжения характеризуются нулевым *внутренним сопротивлением* (импедансом), которое является более общей формой сопротивления, описанной в разделах данной главы, посвящённых переменному току. Короткое замыкание на выводах идеального источника напряжения привело бы к тому, что источник выдал бы бесконечно большой ток. Практические источники напряжения обладают ненулевым внутренним сопротивлением, что также ограничивает отдаваемую ими мощность. Например, если замкнуть выводы практического источника напряжения, такого как 1,5-вольтовый гальванический элемент, через него может потечь ток в несколько ампер; однако его внутреннее сопротивление будет ограничивать величину тока в соответствии с законом Ома — так, как если бы резистор на рис. 2.2 находился внутри элемента или представлял собой его внутреннюю часть.

Источники тока характеризуются бесконечным внутренним сопротивлением. Это означает, что независимо от того, какая нагрузка подключена к выводам идеального источника тока, он будет отдавать один и тот же ток. Разомкнутая цепь на выводах идеального источника приведёт к тому, что на его выводах возникнет бесконечно большое напряжение. Практические источники тока будут повышать выходное напряжение до тех пор, пока не достигнут пределов мощности внутреннего источника питания, после чего начнут снижать выходной ток.

### 2.3.8 Теорема Тевенина и эквивалентные схемы

Теорема об эквивалентном источнике напряжения Тевенина (обычно просто «теорема Тевенина») — полезный инструмент для упрощения электрических цепей или *схем* (формальное название в теории цепей) путём замены исходной цепи более простой эквивалентной. Теорема Тевенина гласит: «Любую двухполюсную цепь, состоящую из резисторов и источников напряжения или тока, можно заменить эквивалентной схемой, включающей один источник напряжения и последовательно включённый резистор».

Теорему Тевенина удобно применить к схеме на рис. 2.6A для нахождения тока через R3. В данном примере (рис. 2.8) схема перерисована так, чтобы показать, как R1 и R2 образуют делитель напряжения, а R3 выступает в роли нагрузки (рис. 2.8А). Ток, потребляемый нагрузкой (R3), равен напряжению на R3, делённому на её сопротивление. Однако значение R2 влияет на напряжение на R3 так же, как наличие R3 влияет на напряжение на R2. Необходимо разделить эти взаимовлияния; для этого строится эквивалентная схема Тевенина, в которой всё, что подключено к зажимам A и B, заменяется одним источником напряжения (эквивалентное напряжение Тевенина, $E_{THEV}$) и последовательным резистором (эквивалентное сопротивление Тевенина, $R_{TH}$).

Первым шагом при построении эквивалентной схемы Тевенина является определение напряжения холостого хода, измеряемого при отсутствии тока нагрузки на зажимах A или B. При разомкнутой цепи между A и B общий ток в цепи (согласно закону Ома):

$$I = \frac{E}{R1 + R2}$$

$$E_{AB} = I \times R2$$

Подставив выражение для тока вместо I, получаем формулу для $E_{AB}$, в которой все величины известны:

$$E_{AB} = \frac{R2}{R1 + R2} \times E$$

Подставляя значения из нашего примера, получаем:

$$E_{AB} = \frac{20.0 \text{ кОм}}{25.0 \text{ кОм}} \times 250 \text{ В} = 200 \text{ В}$$

Эквивалентное сопротивление между зажимами A и B обозначается как $R_{THEV}$. Оно вычисляется как эквивалентная схема на зажимах A и B при замене всех источников напряжения или тока их внутренними сопротивлениями. Идеальный источник напряжения по определению имеет нулевое внутреннее сопротивление и заменяется коротким замыканием (замыкающей перемычкой). Идеальный источник тока обладает бесконечным внутренним сопротивлением и заменяется разомкнутой цепью.

Принимая батарею за приближение идеального источника, заменим её на короткое замыкание между точками X и Y в схеме рисунка 2.8А. С точки зрения зажимов A и B резисторы R1 и R2 оказываются включёнными параллельно. Тогда эквивалентное сопротивление Тевенина $R_{\text{THEV}}$ равно:

$$R_{THEV} = \frac{R1 \times R2}{R1 + R2}$$

$$R_{THEV} = \frac{5000 \ \Omega \times 20000 \ \Omega}{5000 \ \Omega + 20000 \ \Omega}$$

$$R_{THEV} = \frac{1.0 \times 10^8 \Omega^2}{25000 \Omega} = 4000 \Omega$$

Это даёт эквивалентную схему Тевенина, показанную на рисунке 2.8Б. С точки зрения резистора R3 цепи на рисунках 2.8А и 2.8Б полностью эквивалентны, поэтому вся схема превращается в простую последовательную цепь.

После подключения резистора R3 к зажимам A и B через $R_{\text{THEV}}$ потечёт ток, что вызовет падение напряжения на нём и приведёт к снижению $E_{\text{AB}}$. Ток через резистор R3 равен:

$$I3 = \frac{E_{THEV}}{R_{TOTAL}} = \frac{E_{THEV}}{R_{THEV} + R3}$$

Подставляя значения из нашего примера:

$$I3 = \frac{200 \text{ V}}{4000 \Omega + 8000 \Omega} = 16.7 \text{ mA}$$

Это согласуется со значением, рассчитанным ранее.

Эквивалентная схема Тевенина для идеального источника напряжения с последовательно включённым резистором является хорошей моделью реального источника напряжения с ненулевым внутренним сопротивлением. При использовании этой более реалистичной модели видно, что максимальный ток, который может выдать реальный источник напряжения, равен:

$$I_{sc} = \frac{E_{THEV}}{R_{THEV}}$$

а максимальное выходное напряжение равно $V_{\text{oc}} = E_{\text{THEV}}$.

Синусоидальные источники напряжения или тока моделируются аналогичным образом; при этом следует учитывать, что внутренний импеданс $Z_{\text{THEV}}$ такого источника может быть не чисто активным, а содержать реактивную составляющую, зависящую от частоты.

### 2.3.9 Теорема Нортона и эквивалентные схемы по Нортона

Теорема Нортона — ещё один метод построения эквивалентной схемы. Согласно теореме Нортона, «любой двухполюсник, состоящий из резисторов и источников тока или напряжения, может быть заменён эквивалентным двухполюсником, включающим один источник тока и параллельно включённый резистор». Теорема Нортона для источников тока соответствует теореме Тевенина для источников напряжения. Более того, сопротивление Тевенина, рассчитанное ранее, в точности равно эквивалентному сопротивлению по Нортона.

<span id="page-50-0"></span>Схема, которая была только что проанализирована с помощью теоремы Тевенина, может быть столь же легко исследована и методом Нортона. Эквивалентная схема по Нортона показана на рисунке 2.8C. Ток короткого замыкания эквивалентного источника тока, I<sub>NORTON</sub>, представляет собой ток через зажимы A и B при замене нагрузки (R3) на короткое замыкание. В случае делителя напряжения, изображённого на рисунке 2.8A, короткое замыкание полностью шунтирует R2, и ток равен:

$$I_{AB} = \frac{E}{R1}$$

Подставляя значения из нашего примера, получаем:

$$I_{AB} = \frac{E}{R1} = \frac{250 \text{ В}}{5000 \Omega} = 50.0 \text{ мА}$$

Результирующая эквивалентная схема по Нортона состоит из источника тока 50,0 мА, включённого параллельно резистору сопротивлением 4000 Ом. При подключении R3 к зажимам A и B одна треть тока источника питания протекает через R3, а остальная часть — через R<sub>THEV</sub>. Это даёт ток через R3 равный 16,7 мА, что вновь совпадает с предыдущими выводами.

Эквивалентную схему по Нортона можно преобразовать в эквивалентную схему Тевенина и наоборот. Эквивалентное сопротивление R<sub>THEV</sub> одинаково для обоих случаев; оно включается последовательно с источником напряжения в схеме Тевенина и параллельно источнику тока в схеме по Нортона. Напряжение источника Тевенина равно напряжению холостого хода, появляющемуся на резисторе эквивалентной схемы по Нортона. Ток источника по Нортона равен току короткого замыкания, определяемому схемой Тевенина. Эквивалентная схема по Нортона является хорошей моделью реального источника тока, имеющего конечное внутреннее сопротивление.
