# **22.8 Разъёмы компьютеров**

Большинство соединений между компьютерами и их периферийными устройствами выполняется с помощью многожильных кабелей. Примеры включают экранированные, неэкранированные и плоские кабели. В **таблице 22.59** приведены различные типы компьютерных разъёмов и их распиновка, в том числе используемые для внутренних подключений, например, блоков питания и дисковых накопителей.

# Параллельный порт (DB-25, гнездо)

| Контакт (Pin) | Сигнал (Signal) |
|---|---|
| 1 | Строб (Strobe) |
| 2 | Данные 0 (Data 0) |
| 3 | Данные 1 (Data 1) |
| 4 | Данные 2 (Data 2) |
| 5 | Данные 3 (Data 3) |
| 6 | Данные 4 (Data 4) |
| 7 | Данные 5 (Data 5) |
| 8 | Данные 6 (Data 6) |
| 9 | Данные 7 (Data 7) |
| 10 | Подтверждение (Acknowledge, ACK) |
| 11 | Занят (Busy) |
| 12 | Нет бумаги (Paper Empty, PE) |
| 13 | Выбор (Select, SLCT) |
| 14 | Автоматическая подача (Auto Feed, AF) |
| 15 | Ошибка (Error, ERR) |
| 16 | Инициализация (Initialize, INIT) |
| 17 | Выбор включён (Select In, SIN) |
| 18–25 | Общий провод / Земля (GND) |

*Примечание по терминологии:*  
В русскоязычной технической документации для интерфейса LPT/Parallel Port приняты следующие соответствия: `Strobe` → **строб / сигнал стробирования**, `Data` → **линии данных**, `Acknowledge` → **подтверждение**, `Busy` → **занят**, `Paper Empty` → **нет бумаги**, `Select` → **выбор**, `Auto Feed` → **автоматическая подача**, `Error` → **ошибка**, `Initialize` → **инициализация**, `Select In` → **выбор включён**, `GND` → **общий провод / земля**. Английские сокращения в скобках сохранены для однозначной идентификации в схемах и технической литературе.
