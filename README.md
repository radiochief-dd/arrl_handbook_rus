## Перевод  ARRL Handbook 2021г в формате markdown.

ПЕРЕВОД НЕ ВЫЧИТЫВАЛСЯ! Используйте на свой страх и риск!

Перевод выполнен при помощи локальной модели Qwen3.8-27B + словарь. Перед переводом книга была переведена в markdown формат при помощи marker_single, далее перевод осуществлялся по кускам с разбиением на чанки с последующей сборкой в единые файлы.

Файлы изображений сохранены в папке assets. 

Книга разбита на разделы. Можно загрузить в Obsidian и использовать как справочник.

PS: Изначально перевод делался с целью дальнейшего использования как источник информации для локальных генеративных ИИ.
