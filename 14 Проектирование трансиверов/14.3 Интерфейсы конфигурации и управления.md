# <span id="page-585-0"></span>**14.3 Интерфейсы конфигурации и управления**

Компьютерные интерфейсы управления радиостанциями играют ключевую роль при их использовании во всех случаях, кроме самых простых. Они позволяют контролировать состояние аппаратов, изменять их настройки, настраивать их и управлять ими дистанционно. Программы логирования часто используют их во время конкурсов для автоматического захвата частоты и других данных в журнал соревнований. В сочетании с программами логирования интерфейсы могут применяться для автоматического переключения антенн, поворота роторов и управления другим оборудованием радиостанции.

Каждый производитель радиостанций выбрал или разработал интерфейс для работы со своими аппаратами. Обычно производитель использует единый интерфейс во всей линейке своей продукции. Руководство пользователя и сервисное руководство содержат полную информацию о командах и данных, передаваемых через протокол интерфейса.

# 14.3.1 Icom CI-V

Управляющий интерфейс CI-V от компании Icom, название которого расшифровывается как пятый (V) коммуникационный интерфейс (Communications Interface), представляет собой последовательный «однопроводной» протокол. Он использует электрический интерфейс RS-232 (как правило, с напряжением 5 В вместо стандартных для RS-232 ±12 В), но позволяет подключать несколько трансиверов к одной линии связи CI-V в режиме многоадресного обмена.

Благодаря использованию механизма CSMA/CD (множественный доступ с прослушкой несущей и обнаружение коллизий) несколько радиостанций могут избегать одновременной работы с интерфейсом связи, фиксируя возникновение коллизии и повторяя передачу данных. Это тот же принцип, что применяется в Ethernet 10Base2, где использовался коаксиальный кабель и общая шина связи для нескольких компьютеров.

В протоколе CI-V каждой радиостанции присваивается адрес (который можно изменять), благодаря чему компьютер может обмениваться данными с любым трансивером на шине CI-V. Протокол позволяет настраивать частоту, переключать режимы работы, выбирать каналы памяти и выполнять другие функции. В CI-V данные RS-232 обычно передаются в виде байтов, а команды идентифицируются по их шестнадцатеричным кодам. По сути это бинарный протокол связи. CI-V также используется в более новых трансиверах Ten-Tec, но с добавлением команд, специфичных именно для аппаратов этой марки.

# 14.3.2 Интерфейс CAT (Computer Aided Transceiver)

CAT представляет собой интерфейс управления, построенный на основе электрического стандарта RS-232. Большинство производителей (Kenwood, Yaesu, Elecraft, FlexRadio и др.) реализуют CAT через последовательный порт RS-232 или через интерфейс USB, программно эмулирующий сигналы RS-232. Протокол, применяемый каждым производителем, является проприетарным для данной линейки аппаратуры. В отличие от CI-V, CAT представляет собой протокол связи «точка–точка», то есть предполагается, что по одной шине один компьютер управляет одним трансивером. Протоколы CSMA/CD в данном случае не требуются, однако для каждого приёмника-передатчика необходимо использовать отдельный коммуникационный порт. CAT не является бинарным интерфейсом связи; вместо него используются символы кода ASCII. Подобно CI-V, каждый трансивер поддерживает только те команды, которые имеют отношение к его функционалу.

С распространением технологии USB многие трансиверы теперь позволяют подключать интерфейс CAT через порт USB, который операционная система распознаёт как виртуальный последовательный (COM) порт. При подключении USB-кабеля к компьютеру драйверы USB идентифицируют устройство как коммуникационный порт и создают новый COM-порт в системе. Таким образом, с помощью USB-хаба к одному компьютеру можно подключить несколько трансиверов.

С развитием технологий Ethernet и распространением интернета интерфейс CAT стал также реализовываться поверх стека протоколов TCP/IP — стандартного интернет-протокола. Например, в программном обеспечении *SmartSDR* для трансивера FLEX-6000 предусмотрен модуль CAT, через который открывается TCP/IP-порт, реагирующий на стандартные команды CAT. При этом базовый набор команд остаётся неизменным, меняется лишь транспортный уровень: вместо физического интерфейса RS-232 используется передача данных по сети Ethernet через протоколы TCP/IP. Это обеспечивает относительно простую модернизацию ПО: программы, ранее работавшие с COM-портами (RS-232/USB), получают возможность управлять трансиверами напрямую по сети.

Компания FlexRadio Systems, внедряя поддержку CAT для совместимости с традиционным ПО (программами ведения журналов работы и цифровыми видами связи), одновременно разработала новый интерфейс управления компьютером — API *SmartSDR*. Стандарт CAT ограничивается командами управления двумя гетеродинами (VFO), которые традиционно обозначаются как VFO A и VFO B. Поскольку трансивер FLEX-6000 поддерживает до восьми независимых приёмных каналов («слайсов») (которые для целей управления эквивалентны ВЧГ), стандарта CAT оказывается недостаточно для полного контроля аппаратуры. API *SmartSDR* также использует команды в кодировке ASCII и обеспечивает полный контроль над трансивером как через TCP/IP-порт, так и посредством интерфейса библиотеки динамической компоновки (DLL) для платформы Microsoft *Windows*. Клиентское ПО *SmartSDR* (thin client) для компьютеров под управлением *Windows* реализует все функции отображения информации и управления трансивером именно через API *SmartSDR*.
